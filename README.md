# Онлайн-сервис бронирования переговорных комнат

MVP информационной системы для бронирования офисных переговорных комнат (FastAPI + SQLAlchemy + PostgreSQL/SQLite + Docker + GitHub Actions).

## Основные возможности
- Просмотр списка переговорных комнат и актуального расписания.
- Бронирование комнат на интервал от 1 до 4 часов с защитой от двойного бронирования (HTTP 409).
- Ролевая модель (`USER` и `ADMIN`).
- Бронирование VIP-комнат со статусом `PENDING` и подтверждением администратором.
- Экспорт отчётов по бронированиям в формат CSV.

## Локальный запуск
```bash
pip install -r requirements.txt
uvicorn app.main:app --reload
```
После запуска:
- Веб-интерфейс: `http://127.0.0`
- Документация OpenAPI (Swagger): `http://127.0.0docs`

## Запуск через Docker
```bash
docker-compose up --build
```
